# SocialBridge

## Algorithmic Framework for Community Detection and Influence Maximization in Large-Scale Social Networks Using Greedy Heuristics

SocialBridge analyzes social-network graphs to identify connected communities and select influential users who can maximize information spread.

## Modules

1. **Social Network Graph Construction** — preprocesses user-connection data and builds the graph.
2. **Community Detection** — identifies groups of closely connected users using graph community algorithms.
3. **Influence Maximization Using Greedy Heuristics** — selects influential seed users and evaluates information spread.

## Workflow

Dataset → Preprocessing → Graph Construction → Community Detection → Influence Maximization → Information Spread → Performance Evaluation

## Technology

- Python
- Flask
- NetworkX
- Pandas
- NumPy
- Matplotlib

## Main Parameters

- Number of nodes and edges
- Number of communities
- Modularity score
- Number of seed nodes (k)
- Influence spread / coverage
- Execution time

## Purpose

The framework can support social-media marketing, awareness campaigns, recommendation systems, and large-scale social-network analysis.
